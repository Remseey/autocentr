# PRIMECAR

Цифровая платформа для автоцентра. 

## Основные функции

### Для клиента
- Калькулятор стоимости авто (марка авто + выбранные работы = итоговая цена)
- Поиск по нужному автомобилю
- Фильтры для поиска автомобиля
- Личный кабинет

### Для администратора
- Управление заявками
- Управление авто
- Управление пользователями
- Управление отзывами

## Технологии

- Фронтенд: HTML, CSS, JavaScript
- Бэкенд: NodeJS,  SQL
- База данных: SQL


### Шаги для запуска

1. Скачайте проект
2. Установите NodeJS 20+
3. Установите MySQL
4. Откройте терминал
5. Перейдите в папку с файлом schema.sql(database/schema.sql) например (cd C:\путь\к\проекту\database\schema.sql)
6. Выполните импорт ( mysql -u root -p <schema.sql )
7. Нажмите Enter и введите пароль который вы задали для root
8. Запустите проект 
-npm install
-npm start
9.Откройте сайт в браузере : http://localhost:3000
